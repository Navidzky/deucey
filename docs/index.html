Find someone to play tennis with, nearby.

DEUCEY matches you with nearby players by skill level and shows nearby courts with directions — all without ever sharing your exact location.

Follow the project How it works

How it works

1

Nearby players, by skill

See who's around and up for a match at your level — visible only while you're both marked available to play.

2

Nearby courts, with directions

Public and private courts pulled from real map data, with a one-tap directions link to get there.

3

Private by default

Your exact location never leaves the database. Other players only ever see a rounded distance, never coordinates.

Where things stand

DEUCEY is a working app, not yet on the app stores. It runs on iOS, Android, and web from one codebase, backed by a live Supabase database — sign-up, skill-based matching, and nearby-courts search are all built and working.

Court data is already mapped nationwide (all 50 states + DC), with West Lafayette, Indiana as the first fully-reviewed test market.
